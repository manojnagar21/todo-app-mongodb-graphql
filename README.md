GraphQL Todo Application

A robust, production-ready Todo Application built using the JavaScript backend stack: Node.js, Express, MongoDB, and GraphQL. This project demonstrates how to build a flexible API using GraphQL queries and mutations instead of traditional REST endpoints.

🚀 Features

• Full CRUD Operations: Create, read, update, and delete todo items.
• GraphQL API: Single endpoint (/graphql) to fetch exactly the data you need.
• Database Integration: Persistent data storage using MongoDB and Mongoose.
• Status Toggling: Easily mark todos as completed or pending.
• Interactive Playground: Built-in GraphiQL interface for testing queries and mutations in the browser.

🛠️ Tech Stack

• Backend: Node.js, Express.js
• API Layer: Core GraphQL
• Database: MongoDB, Mongoose (ODM)
• Environment Management: Dotenv
